# Emuladores suportados

| Emulador | Console |
| --- | --- |
| **PPSSPP** | PlayStation Portable |
| **PCSX2** | PlayStation 2 |

Para cada emulador, o Slot2Sync pode sincronizar até três categorias de arquivo —
detalhadas em [Sincronização](sincronizacao.md#categorias):

- **saves** — os progressos salvos dentro do jogo;
- **savestates** — os "estados" instantâneos do emulador;

## Quer sugerir um novo emulador?

A estrutura do Slot2Sync foi pensada para crescer sem reescrever o núcleo do app — abra
uma [issue no GitHub](https://github.com/jIDvDIj/slot2sync/issues) descrevendo o
emulador e onde ele guarda saves/savestates no seu sistema operacional.
