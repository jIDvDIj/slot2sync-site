# Instalação

## Windows

1. Baixe o instalador mais recente na página de
   [releases do Slot2Sync](https://github.com/jIDvDIj/slot2sync/releases/latest)
   (`.exe` ou `.msi`).
2. Execute o instalador e siga o assistente.
3. Na primeira execução, o Windows SmartScreen pode exibir um aviso porque o instalador
   é de um desenvolvedor independente. Clique em **Mais informações → Executar assim
   mesmo** para prosseguir.

## macOS

Baixe o `.dmg` correspondente ao seu processador (Apple Silicon ou Intel) na página de
[releases do Slot2Sync](https://github.com/jIDvDIj/slot2sync/releases/latest) e arraste
o app para a pasta Aplicativos.

## Linux

Baixe o pacote correspondente à sua distribuição na página de
[releases do Slot2Sync](https://github.com/jIDvDIj/slot2sync/releases/latest):
`.deb`, `.rpm` ou `.AppImage`.

!!! info "Android"
    Suporte a Android está em desenvolvimento. Acompanhe o progresso nas
    [releases do projeto](https://github.com/jIDvDIj/slot2sync/releases).

## Requisitos

- Uma conta Google, para conectar ao Google Drive, ou uma pasta local/de rede como
  armazenamento (sem precisar de conta).
